# Exereal Launcher

Мы разрабатываем кастомный лаунчер Minecraft с изолированными инстансами, поддержкой лицензионных и пиратских аккаунтов.

</div>

---

### [Exereal Launcher](https://github.com/Exereal-Launcher/Exereal-Launcher)

Лаунчер Minecraft с:
- изолированными инстансами (свои моды/сохранения/конфиги у каждого, как в Prism Launcher)
- менеджером аккаунтов — несколько локальных и Microsoft-аккаунтов с переключением
- установкой Vanilla / Fabric / Forge прямо из интерфейса
- многоязычным интерфейсом (EN / ES / FR / RU)
